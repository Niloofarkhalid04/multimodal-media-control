\# Multimodal Gesture-Based Media Controller 🎧



A real-time computer vision system that enables hands-free control of media playback using a standard webcam.



The project combines hand gestures, face movement, and eye blink detection to create a multimodal Human–Computer Interaction (HCI) experience.



---



\## Features

\- 👁️ Eye blink → ▶️ Play / ⏸️ Pause

\- 🙂 Head turn → ⏮️ Previous track / ⏭️ Next track

\- ✋ Hand gestures:

&nbsp; - ☝️ Index finger → 🔊 Volume Up

&nbsp; - 🤟 Three fingers → 🔉 Volume Down

&nbsp; - ✊ Fist → 🔇 Mute

&nbsp; - ✋ Open palm → 🔈 Unmute



All interactions work in real time without any physical input devices.



---



\## Technologies Used

\- Python

\- OpenCV

\- MediaPipe (Face Mesh)

\- CVZone (Hand Tracking)

\- PyAutoGUI



---



\## Project Highlights

\- Designed a multimodal interaction pipeline combining face, eye, and hand inputs

\- Implemented neutral zones, cooldowns, and state control to prevent false triggers

\- Addressed real-world computer vision challenges such as:

&nbsp; - lighting variations

&nbsp; - jitter and noise

&nbsp; - pose ambiguity

\- Focused on usability and interaction stability, not just gesture detection
